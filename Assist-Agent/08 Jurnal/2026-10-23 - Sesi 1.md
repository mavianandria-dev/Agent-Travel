# 2026-10-23 — Sesi 1

## Tujuan

Membuat vault memori `Assist-Agent/` untuk mempelajari dan merawat codebase TransAceh.

## Yang dipelajari

- Aplikasi aktif ada di `transaceh-react/`; root `index.html` adalah versi legacy.
- Navigasi memakai `view` di `AppContext`, bukan React Router.
- Data disimpan di `localStorage` dengan prefix `at_`.
- `domain.js` adalah pusat aturan bisnis dan bercampur dengan akses data.
- `seed.js` memakai `at_seeded_v16` + banyak migrasi.
- Empat peran: pelanggan, agen, pengemudi, superadmin.
- Booking → payment → ledger → settlement adalah rantai utama.
- Refund pelanggan hanya tiket; refund operator/no-show memakai total.
- AI memakai Cloudflare Worker agar API key tidak masuk frontend.
