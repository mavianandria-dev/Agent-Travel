# 2026-10-26 — Sesi 8

## Tujuan

Migrasi penyimpanan Google Sheets dari "1 baris = 1 sel JSON" (schema 1) ke **skema kolom relational 1NF penuh** (schema 2), lalu menaikkan harness lokal agar seluruh lapisan (schema, engine, seed, validator) teruji sebelum rollout produksi.

## Keputusan

### 1. Storage v2 — tidak ada JSON di dalam sel

- Semua field skalar menjadi kolom pada tab utama; setiap array/objek dipecah ke tab anak (`~40 tab`) dengan `parent_id` + `slot`/`key` (`code.gs:519-845`, `API_MAIN_TABLES`).
- Semua nilai disimpan sebagai teks (format sel `'@'`); prefix kolom menentukan konversi saat baca: tanpa prefix = string, `n:` = number, `b:` = boolean. Sel kosong dibaca `''` (teks) atau `null` (angka/boolean).
- Alias kolom `src>col` untuk nama field yang bentrok (`id>msg_id` pesan tiket); flag `scalar: true` memakai satu kolom `val` untuk list/map elemen skalar; path anak bisa bertingkat (`kyc.alamat`).
- Field di luar skema ditolak dengan `VALIDATION` (anti silent data-loss); pengecualian `notifications` memakai path `'*'` yang menampung field ekstra skalar ke `notifications_meta`.
- Array selalu dimaterialisasi `[]` saat dibaca (kontrak baca v2) — perbandingan field server harus memahami kontrak ini.

### 2. Password plaintext tidak pernah jadi kolom

- `pass`/`password` hanya **field transien** pada `sync` `users`: di-hash `apiSyncPrepareUsers_` sebelum tulis; `apiValidateRecordSchema_` menerima field transien via `API_TRANSIENT_FIELDS_` sehingga `sync` tidak ditolak, sedangkan `commit` (superadmin) tetap menolak field rahasia.
- Seed mem-hash admin sejak seeding lewat pepper `setupBackend()`; urutan wajib: `setupBackend()` → `seedProduction()`.

### 3. Perbandingan field mengikuti semantik kolom

- `apiSyncChangedFields_` kini memakai `apiSyncValueChanged_`: nilai kosong (absen/`null`/`''`) sederajat karena penyimpanan kolom tidak membedakan field tak diisi dan field kosong; angka vs teks-angka dibandingkan numerik.
- Booking tidak lagi membawa objek `fare`; diganti kolom `fareTicket/fareService/fareFee/fareTotal` (`sync` whitelist, estimasi refund dipakai `booking.fareTicket` dengan fallback `apiSyncSplitFare_`).
- Whitelist pengemudi pada jadwal diselaraskan nama field `domain.js` (`delayedAt`/`delayedBy`/`delayMinutes`/`delayAddedMinutes`/`tripDelayUpdatedAt`); nama lama `delayReportedAt`/`delayReportedBy` dihapus.

### 4. Seed dan validasi v2

- `seed.gs` dibangun ulang: membuat semua tab dari `apiDescribeStore_()`, hash password sebelum menyentuh sheet, `_meta` v2 (`schemaVersion`/`storage`/`tableCount`), dan `validateDatabase()` memeriksa header per tabel, duplikat, orphan `parent_id`, guard sel 45000, serta membaca ulang tiap koleksi lewat engine baca.
- Tidak ada migrasi data: spreadsheet produksi harus **di-reset** lalu di-seed ulang.

### 5. Harness jadi penggerbang

Harness kini memuat `seed.gs` ke sandbox yang sama, membuat tab dari skema, men-seed lewat `apiWriteCollection_`, membaca record lewat `readRec()` (`apiReadCollection_` — bukan sel JSON), dan menambah uji round-trip tulis/baca semua koleksi + tolak sel > 45000 karakter + tolak field tak dikenal tanpa data loss.

## Perubahan

- `code.gs` 1.2.0 → **1.3.0** (`DB`/`API_SCHEMA_VERSION '2'`, `API_ROW_HEADERS`, `API_MAX_CELL_CHARS`); engine baca/tulis kolom + validator skema menggantikan engine JSON.
- `seed.gs` dibangun ulang penuh untuk format kolom (`DB_SEED_VERSION 'production-2'`).
- `mock-harness.mjs` diperbarui menyeluruh: mock Apps Script lebih lengkap (`setNumberFormat` range, styling sheet, `insertSheet`/`deleteSheet`/`getSheets`, `clearContents`, flush), fixture di-hash via `apiHashForUser_`, KYC berbentuk `docs` objek, ledger/route/booking fare sesuai kolom.
- Dokumentasi diperbarui: `README.md` format v2 + reset mandatory + urutan setupBackend dulu; vault: [[Database Google Sheets]], [[00 Data Model MOC]], [[Peta Repository]], [[Tech Stack]], [[Build dan Deploy]], [[Quick Reference]], [[00 Arsitektur MOC]], [[Technical Debt dan Jebakan]], [[File Index]], [[00 Index]].

## Risiko dan keterbatasan

- DataUrl foto nyata (KYC/media) masih bisa melebihi 45.000 karakter per sel — perlu Drive privat + endpoint media.
- Multi-koleksi belum atomik; lifecycle belum server-side; CORS browser belum diprobe.
- Data produksi lama (format JSON) tidak dapat dibaca engine v2 — reset wajib.

## Langkah berikutnya

1. Commit perubahan v2 (code.gs 1.3.0 + seed.gs + harness + README).
2. Reset spreadsheet produksi → `setupBackend()` → `seedProduction()` → `validateDatabase()`; verifikasi `health` versi 1.3.0 / schemaVersion 2.
3. Probe CORS dari origin produksi + dev, lalu E2E semua peran dengan data sintetis.
4. Setelah lulus, ubah `VITE_DATA_MODE=sheets` (workflow env), tetapi `.env` tetap `local`.
